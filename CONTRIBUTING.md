# Контрибуция в pylzt

Python 3.12+, менеджер — [uv](https://docs.astral.sh/uv/).

## Установка

```bash
git clone https://github.com/open-lzt/pylzt && cd pylzt
uv sync --extra dev
git config core.hooksPath .githooks   # локальный гейт ruff+mypy+pytest на push
```

## Гейт

`.github/workflows/ci.yml` гоняется на каждый push и PR:

```bash
uv run ruff check src tests
uv run mypy
uv run pytest -q
```

`.githooks/pre-push` повторяет его локально, чтобы красное ловилось до пуша. Не обходите его.

E2E-тесты бьют по живому API, требуют `LZT_E2E_TOKEN` и исключены по умолчанию — `uv run pytest -m e2e -q`.

## Сгенерированный код

Методы, модели ответов, енумы и фасады в `src/pylzt/{methods,models,enums,facades}/` рендерятся из OpenAPI-спеки и несут docstring `Generated by forge — DO NOT EDIT`. **Реген затрёт правку руками.**

Меняйте генератор или механизм ручных патчей — см. [`docs/codegen-runbook.en.md`](docs/codegen-runbook.en.md) (на английском). Реген — `python -m dev.codegen build`, обновлённые `dev/generated/openapi/*.json` коммитятся тем же коммитом, что и диф кодогенерации.

Изменилась публичная сигнатура — обновите [`docs/integration-guide.md`](docs/integration-guide.md) в том же PR.

## Релиз (для мейнтейнеров)

Публикация идёт по тегу: `.github/workflows/release.yml` собирает sdist и wheel, прогоняет гейт, публикует на PyPI через OIDC trusted publishing (токена в secrets нет) и создаёт GitHub Release с автосгенерированными заметками.

1. Поднимите `version` в `pyproject.toml`. Semver: багфиксы → patch, новые эндпоинты или опции → minor, изменённая публичная сигнатура → major.
2. Закоммитьте бамп.
3. Поставьте тег и запушьте:

```bash
git tag v0.2.1 && git push origin main v0.2.1
```

Тег обязан совпадать с версией в `pyproject.toml`. PyPI не даёт перезаписать существующую версию, поэтому расхождение или переиспользованный тег упадут на шаге публикации — уже после того, как сборка прошла.

`-rc`, `-alpha` или `-beta` в теге помечают GitHub Release как предрелиз.

## Pull request'ы

PR идут в `main`. Одно логическое изменение на PR, на новое поведение — тест.
